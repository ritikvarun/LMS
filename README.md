# LMS - Full Stack Learning Management Platform

A modern, high-performance Learning Management System (LMS) built with React (Vite) and Node.js (Express & MongoDB).

## Features
- **Curriculum & Video Track Manager:** Multi-video lessons under organized topics (e.g. AI 1.1, 1.2, 1.3... ML 2.1, 2.2, 2.3...) with ordering.
- **Dedicated Course Sections:** Clean separation between Paid / Pro Masterclasses and 100% Free Foundation Batches.
- **Interactive Student Player:** Sequential lecture viewing, video player, progress tracking, and notes downloads.
- **Real-time Live Classes:** Live broadcasts, interactive lobbies, and schedule notifications.
- **Mock Tests & Examination Engine:** Timed test attempts, question review palette, and instant scorecards.
- **Payment & Coupon System:** Secure Razorpay checkout with discount coupons.
- **Educator Studio:** Comprehensive admin panel for courses, curriculum, books, and live sessions.

## Tech Stack
- **Frontend:** React, Redux Toolkit, TailwindCSS, React Router 6, React Icons
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT, Cookie Parser
- **Media & Storage:** Bunny CDN, Cloudinary
- **Payments:** Razorpay API
